Welcome to the official documentation for **pipelite**, a lightweight and extensible Python framework for building data pipelines through simple JSON configuration.

---

## Documentation Overview

This documentation is organized into four main sections to help you get the most out of pipelite:

### 📚 [Quick Start Guide](quickstart.md)
Get up and running with pipelite in minutes. Perfect for first-time users who want to create their first pipeline quickly.

### 🔧 [How-To Guides](howto/index.md)
Task-oriented guides that walk you through common use cases and scenarios:
- Creating your first pipeline
- Connecting to databases
- Transforming data
- Profiling datasets
- Extending pipelite with custom components

### 📖 [Complete Guide](guide/index.md)
Comprehensive documentation covering all aspects of pipelite:
- Installation and setup
- Configuration reference
- Data sources
- Transformers
- Pipeline management
- Logging and monitoring

### ⚙️ [Technical Documentation](technical/index.md)
In-depth technical documentation for developers:
- Architecture overview
- API reference
- Extension development
- Contributing guidelines
